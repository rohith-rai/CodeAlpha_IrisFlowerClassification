# Iris Flower Classification

This project is part of my Data Science Internship at *CodeAlpha*.

## About
The goal is to classify Iris flowers into three species — Setosa, Versicolor, and Virginica — based on their sepal and petal measurements, using machine learning.

## Dataset
The dataset (⁠ Iris.csv ⁠) contains 150 samples with the following features:
•⁠  ⁠Sepal Length
•⁠  ⁠Sepal Width
•⁠  ⁠Petal Length
•⁠  ⁠Petal Width
•⁠  ⁠Species (target)

## Steps Followed
1.⁠ ⁠Loaded and explored the dataset
2.⁠ ⁠Cleaned the data
3.⁠ ⁠Visualized relationships between features using pairplots and boxplots
4.⁠ ⁠Split the data into training and test sets
5.⁠ ⁠Trained two models: *K-Nearest Neighbors* and *Logistic Regression*
6.⁠ ⁠Evaluated model accuracy using a classification report and confusion matrix

## Results
Both models achieved high accuracy (95–100%) in classifying the three species, with petal length and petal width being the most important features.
